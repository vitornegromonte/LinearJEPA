# LeWorldModel — Optional GPU kernel dependencies
# ------------------------------------------------------------
# These packages provide CUDA-accelerated implementations of the
# Mamba (mamba_ssm) and DeltaNet (fla) predictors. Without them,
# the code falls back to pure-PyTorch implementations (correct,
# but significantly slower on GPU).
#
# IMPORTANT: All three require a CUDA toolkit (nvcc) that matches
# your PyTorch build. If any fail to install, skip them — the code
# will still run correctly using fallback implementations.
#
# Install:
#     pip install --no-build-isolation -r requirements-cuda.txt
#
# If mamba-ssm or causal-conv1d fail due to CUDA version mismatch,
# install just flash-linear-attention (the most portable one):
#     pip install --no-build-isolation flash-linear-attention
# ------------------------------------------------------------

# Flash Linear Attention (linear attention CUDA kernels,
# includes DeltaNet — fla.layers.DeltaNet).
# This is the most portable of the three and provides the
# biggest speedup for DeltaNetConditionalBlock.
#
# Versions >= 0.3.2 require PyTorch >= 2.7 + Triton >= 3.3.
# If install fails with a "torch >= 2.7 required" build error,
# pin an older version:
#     pip install --no-build-isolation flash-linear-attention==0.2.2
flash-linear-attention
