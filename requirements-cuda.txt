# LeWorldModel — Optional GPU kernel dependencies
# ------------------------------------------------------------
# These packages provide CUDA-accelerated implementations of the
# Mamba (mamba_ssm) and DeltaNet (fla) predictors. Without them,
# the code falls back to pure-PyTorch implementations (correct,
# but significantly slower on GPU).
#
# Install (note: --no-build-isolation is required so pip uses
# the installed GPU PyTorch instead of an isolated torch-cpu):
#     pip install --no-build-isolation -r requirements-cuda.txt
#
# Notes:
# - mamba-ssm requires `nvcc` on the system. Colab ships with it.
# - The build is usually fast on Colab because mamba-ssm auto-
#   downloads a pre-built wheel from GitHub Releases via its
#   `CachedWheelsCommand` mechanism.
# ------------------------------------------------------------

# Mamba SSM (state-space model CUDA kernels)
causal-conv1d>=1.4.0
